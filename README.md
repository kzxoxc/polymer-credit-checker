# 고분자공학과 학점 계산기

인하대학교 고분자공학과 성적증명서 PDF를 올리면 학번(입학년도)별 교과과정표를 기준으로
전공필수 잔여 과목, 전공선택 잔여학점, 재수강 대상, 교양 요건 이수 현황을 보여주는 웹앱입니다.

## 바로 사용하기

**https://polymer-credit-checker.lovable.app/** 에서 바로 쓸 수 있습니다.
(기존 주소 https://polymer-credit-checker.onrender.com/ 로 접속하면 위 주소로 자동 이동합니다.)

프론트엔드는 Lovable에, 백엔드 API(OCR·졸업요건 분석)는 이 저장소 그대로 Render에 배포되어 있습니다.
Render 무료 플랜이라 한동안 접속이 없으면 서버가 잠들고, 첫 분석 요청이 응답하는 데 30초~1분 정도
걸릴 수 있습니다. 이 링크로 쓰는 경우 아래 Gemini API 키 발급은 필요 없습니다(서버에 이미 설정되어 있음).
API 키 발급은 로컬에서 직접 실행하거나 개발하고 싶은 경우에만 필요합니다.

## 로컬에서 직접 실행하기

### 1. Gemini API 키 발급 (무료)

PDF에서 표를 읽어오는 OCR 기능은 Google Gemini API를 사용합니다. (사진 업로드는 인식 정확도가 낮아 지원하지
않고, PDF만 받습니다 — 인하대 증명서 발급 시스템에서 PDF로 발급받으면 됩니다.)

**성적증명서 PDF 발급 경로**: 인하포털 학사행정시스템 → 학사행정 → 성적 → 성적 및 석차확인 → 조회 후 PDF 저장

1. https://aistudio.google.com/apikey 접속 후 구글 계정으로 로그인
2. "Create API key" 클릭 → 키 복사
3. `server/.env.example`을 복사해서 `server/.env` 파일을 만들고 키를 붙여넣기

```
cp server/.env.example server/.env
# server/.env 파일을 열어서 GEMINI_API_KEY=발급받은키 로 수정
```

### 2. 패키지 설치

```
npm run install:all
```

### 3. 실행

```
npm run dev
```

브라우저에서 http://localhost:5173 접속 (서버는 3001 포트에서 API를 제공, Vite가 자동으로 프록시합니다).

OCR 없이 직접 표를 입력해서 써볼 수도 있습니다 ("OCR 없이 직접 입력하기" 버튼).

## 폴더 구조

- `data/curricula/2021.json ~ 2026.json` — 학번별 졸업요건 데이터. 학과 공지가 바뀌면 이 파일들만 고치면 됩니다.
- `data/coreElectiveAreas.json` — 핵심교양 1/2/4/6영역 + SW·AI(일반교양 7영역) 개설과목 목록(학번과 무관한 학교
  공통 데이터). 매 학기 과목이 추가/폐지되니 새로운 과목이 있으면 이 파일에 추가하면 됩니다.
- `data/convergenceMajors/*.json` — 융합전공(복수전공/부전공) 데이터. 현재 반도체융합전공만 있음.
- `server/` — Express API (OCR 호출 + 분석 로직)
- `client/` — React 프론트엔드

## 졸업요건 (공식 확인됨, 20~26학번 동일)

- 졸업학점: 130학점 이상 취득 (일반+교양+전공)
- 전공학점: 65학점 이상 취득 (단일전공 기준). 융합전공을 복수전공으로 선택하면 고분자전공 39학점 + 융합전공
  39학점(총 78학점), 부전공으로 선택하면 고분자전공 44학점(=65-21) + 융합전공 21학점 기준으로 자동 전환됩니다.
- 본인 학번의 전공필수·교양필수 과목은 졸업 전까지 모두 이수
- **영어졸업인증**: 재학 중 1회 이상 학과 사무실에 기준 이상의 영어성적표 제출 필요(제출 시 유효기간 2개월 이상 남아있어야 함).
  성적증명서로는 확인이 안 되는 항목이라 이 앱은 자동 판정 없이 안내만 합니다. ([안내 페이지](https://www.inha.ac.kr/kr/1051/subview.do))

## 알아둘 점 (데이터 한계)

- **핵심교양 1/2/4/6영역 + 창의영역 + SW·AI(일반교양 7영역)** 모두 `data/coreElectiveAreas.json`에 정리된 실제
  개설과목 목록으로 이수 여부를 정확히 판정합니다(과목명 기준 매칭, 학수번호는 학기마다 바뀌어서 사용 안 함).
  창의영역은 학기마다 개설과목(주로 창업/기업가정신 관련)이 자주 바뀌므로, 목록에 없는 새 과목을 들었다면
  `data/coreElectiveAreas.json`의 `areas.changui.courses`에 추가해주세요.
- 2022학번 계열교양 목록은 원본 PDF 표가 일부만 보여서, 이수체계도 및 실제 학생 성적표를 근거로 2021학번과
  동일하다고 가정했습니다.
- 2025/2026학번은 학과 종합정보시스템 원본 표로 확정: 전공기초에 물리학실험1·2 없음, 전공선택에 현장실습6 없음,
  교양필수에 프로네시스 세미나 없음(대신 커리어디자인1 있음).
- 업로드한 PDF와 추출된 성적 데이터는 서버에 저장되지 않고 메모리에서만 처리됩니다(개인정보 보호).
- 과목 분류는 9개 카테고리로 관리합니다: 전공필수, 전공선택, 계열교양, 기초교양(교양필수), 핵심교양(교양필수),
  창의(교양필수), SW·AI(교양필수), 일반교양, 융합전공(선택 시). 위 8개 카테고리 어디에도 안 걸리는 과목은
  전부 "일반교양"으로 표시됩니다(다른 학과의 복수전공/부전공 과목 포함).

## 융합전공(복수전공/부전공)

1단계 업로드 화면에서 융합전공을 선택하면(현재는 **반도체융합전공**만 있음) 이수 형태(복수전공 39학점 /
부전공 21학점)에 맞춰 결과 화면에 별도 카드로 진행률을 보여줍니다.

- 주전공(고분자공학과) 매칭을 먼저 시도하고, 거기서 안 걸린 과목만 융합전공 목록과 대조합니다. 재료과학처럼
  두 전공에 공통으로 개설되는 과목도 이 방식으로 자동으로 중복 계산되지 않습니다.
- 두 전공 목록에 다 있는 과목(예: 재료과학)은 결과 화면 하단 "주전공/융합전공 양쪽에 해당하는 과목"에서
  버튼 클릭으로 어느 쪽 학점으로 인정할지 직접 옮길 수 있습니다(기본값은 주전공).
- 반도체융합전공 원본 문서의 "전공필수 15학점(복수전공)/9학점(부전공)" 기준은 학칙상 "필수+직무훈련으로도
  못 채운 학점은 전공선택으로 대체"되므로, 이 앱은 [고정 필수과목 2개(4학점) + 직무훈련 최소 3학점] 이후
  나머지는 전공선택 합계로 39/21학점을 채우는 방식으로 단순화했습니다. 자세한 내용은
  `data/convergenceMajors/반도체융합전공.json`의 `_notes` 참고.
- 강원대 학점교류(공동학위) 트랙은 반영하지 않았습니다.
- **특성화이차전지융합전공**은 아직 데이터가 없어 추가 예정입니다.
- 복수전공/부전공 매칭은 학수번호가 아니라 과목명 기준이라 코드 접두어(PSE/SEC/...)가 겹치거나 달라도 상관
  없습니다.
